the computer i use at work is painfully slow.

16gb of ram, i5-11320h @ 3.2ghz, 256gb ssd and all it needs to do is run word and emails.  surely thats not hard for that much computer?

i'm aware that its not the best machine ever, far from it.  however it feels like this should be enough computing power for what i'm using it for.

microsoft word, emails, and pdfs have existed for ages, i could do the same work on a windows xp machine.  replace one drive with network attached storage, and it would all work with technology thats older than i am

but no, instead i've got windows 11, with all its ~~amazing~~ awful ai features and corporate end point security that uses more ram than anything i'm actually using the machine for.  and thank you adobe acrobat for opening 12 copies of webview 2 just so i can add comments to a pdf.  12 web views to open a pdf.  the word doc that the pdf was made from is currently open and using 15% of the ram that acrobat does 86mb for word vs 589 for acrobat. why??

i regularly have this machine take multiple minutes just to rename a folder. wtf?

has everyone forgotten that efficiency is something that exists?
